rclone-skynet

Домашняя страница и политика конфиденциальности личного OAuth-приложения для rclone.

Назначение: автоматическое резервное копирование личных данных с домашнего сервера skynet в личный Google Drive владельца аккаунта.

  • Данные передаются только между сервером владельца и его собственным Google Drive.
  • Третьим лицам данные не передаются, не продаются и не анализируются.
  • Приложение не собирает телеметрию и используется только владельцем.
  • Доступ предоставляется через стандартный OAuth-Flow Google; отзыв доступен в настройках аккаунта.

Контакт: владелец аккаунта GitHub JoKeR130482.
